# Task 18: Output Screenshots Guide

## 1. Overview
This document outlines the 8 essential screens of the **IMovies** application to capture for your college project report, submission PDF, and viva presentation slides.

Save the captured screenshots in the `docs/screenshots/` directory with the following standardized filenames.

## 2. Recommended Screenshots Checklist

| # | Screen Name | Suggested Filename | Key Elements to Showcase |
| :-: | :--- | :--- | :--- |
| **01** | **Home Page (Movie Listing)** | `01_home_movies.png` | Hero banner, search bar, genre/language filter dropdowns, and movie cards with ratings and status badges. |
| **02** | **Movie Details & Showtimes** | `02_movie_details.png` | Backdrop banner, movie synopsis, cast, director, date tabs, and multiplex showtime buttons. |
| **03** | **Interactive Seat Map** | `03_seat_selection.png` | Curved cinema screen, tiered seating (Silver, Gold, Platinum), booked vs available seats, and real-time total price sidebar. |
| **04** | **Simulated Checkout** | `04_checkout_payment.png` | Order breakdown, demo payment method selector, and the "Simulate Payment Success" & "Simulate Payment Failure" action buttons. |
| **05** | **Digital Ticket Confirmation** | `05_ticket_confirmation.png` | Confirmed ticket stub with unique Booking Reference (`IM-XXXX-XXXX`), barcode graphic, and "Print Ticket" button. |
| **06** | **Customer Booking History** | `06_booking_history.png` | List of confirmed and cancelled bookings with status badges and the "Cancel Ticket" action button. |
| **07** | **Authentication Screen** | `07_login_screen.png` | Clean login form featuring the 1-click **College Demo Quick-Fill** buttons for Admin and Customer accounts. |
| **08** | **Administrator Dashboard** | `08_admin_dashboard.png` | Metric analytics cards (Simulated Revenue, Total Bookings, Movies, Shows), and the Recent Bookings activity table. |

## 3. How to Capture Clean Screenshots
1. Start the backend (`npm run server`) and frontend (`npm run client`).
2. Open your browser in full screen (1920x1080 resolution is recommended for viva slides).
3. Open Developer Tools (F12) -> Run Command -> "Capture full size screenshot" or use Windows shortcut `Win + Shift + S`.
4. Save the image files into `docs/screenshots/`.
